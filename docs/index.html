What it does

        
Made for touch first, and careful with your work.

        

          

            
            
Made for touch
Pinch to zoom the code, a row of coding keys above the keyboard, and buttons big enough for a thumb.

          

          

            
            
27 languages
Proper colours, folding and word suggestions for the languages people use every day.

          

          

            
            
Runs your code offline
Open a web page with its CSS and JavaScript, or run a Python script, right on the phone with no internet.

          

          

            
            
Hard to lose work
Auto-save, unsaved changes that survive the app closing, and older versions of every file you can bring back.

          

          

            
            
Works with GitHub
Download a project from GitHub or GitLab, edit it, and send your changes back as a pull request.

          

          

            
            
Private
No account and no tracking. Your files stay on your phone. The offline edition asks for no permissions at all.
