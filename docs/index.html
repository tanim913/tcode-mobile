Tcode Mobile

A free, open-source code editor for Android. Built for a phone screen and a thumb, and it works without internet.

Download for Android View on GitHub

Free. No ads, no sign-up, no tracking. Android 7.0 or newer.

What it does

Made for touch

Pinch to zoom the code, a row of coding keys above the keyboard, and buttons big enough for a thumb.

27 languages

Proper colours for Python, JavaScript, HTML, CSS, Dart, Java, Kotlin, C, C++, Go, Rust, PHP and more.

Runs your code offline

Open a web page with its CSS and JavaScript, or run a Python script, right on the phone with no internet.

Hard to lose work

Auto-save, unsaved changes that survive the app closing, and older versions of every file you can bring back.

Works with GitHub

Download a project from GitHub or GitLab, edit it, and send your changes back as a pull request.

Private

No account and no tracking. Your files stay on your phone. The offline edition asks for no permissions at all.

How to install

  1. Open the latest release on your phone.
  2. Download the file that ends in arm64-v8a.apk. It works on almost every phone.
  3. Open it. If your phone asks, allow your browser to install apps.
  4. If Play Protect warns you, tap Install anyway. It says that about any app that is not from the Play Store.
