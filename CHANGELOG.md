## [1.0.0] - 2026-09-24

First public release.

### Editing
- Syntax highlighting for 27 languages, code folding (by braces, and by
  indentation for Python and YAML), word completion, snippets, and find and
  replace with regex.
- Pinch to zoom, a row of coding keys above the keyboard, a selection toolbar,
  and a lock that makes a file read-only.

### Projects and files
- Open the Projects folder, any folder on the phone, or a downloaded
  repository.
- Explorer with undoable file operations, drag to move, and ZIP import and
  export.
- Tabs with preview, reorder and reopen closed.
- Recent folders and files.

### Finding things
- Command palette, go to file, go to line, outline, workspace search and
  replace, and Find in Folder.

### Running
- Run HTML pages and JavaScript with a console.
- Run Python with MicroPython.
- Markdown preview and JSON formatting.

### Safety
- Auto-save and hot exit.
- Local file history with compare and restore.
- A banner when a file changes on disk.

### GitHub and GitLab (standard edition)
- Download public repositories; with a token, private ones too.
- Create pull requests (GitHub) and merge requests (GitLab) from your changes.
